# 츄테크

TQQQ와 SGOV를 섀넌의 도깨비 전략으로 굴릴 때, 오늘 걸 LOC 주문(수량, 지정가)을 계산해 주는 iPhone용 웹앱(PWA)이에요.
AppSheet, 구글 시트 없이 이 파일들만으로 동작하고, 기본적으로 데이터는 폰 안에만 저장돼요. (자동 알림을 켜면 보유 수량과 설정이 내 Cloudflare 서버에도 저장돼요.)

## 파일 구성 (저장소 맨 위 폴더에 그대로 올리기)

```
index.html
style.css
logic.js              ← 전략 계산 (비중, 지정가, 수량, 투입금 배치)
app.js                ← 화면과 동작
sw.js                 ← 오프라인 지원
manifest.webmanifest  ← 홈 화면 앱 정보
icons/
  icon-180.png
  icon-192.png
  icon-512.png
  icon-512-maskable.png
```

알림 기능용 파일은 **저장소에 올리지 않아요**.

```
알림설정.md           ← 자동 알림 설정 순서 (관리하는 분이 한 번 따라 하기)
worker/worker.js      ← Cloudflare Worker에 통째로 붙여 넣는 서버 코드
```

## 올리는 방법 (GitHub Pages)

1. GitHub에서 새 저장소를 만들어요 (예: `quant-navigator`, Public).
2. 위 파일과 `icons` 폴더를 저장소 맨 위에 올려요 (Add file, Upload files).
3. Settings, Pages에서 Branch를 `main`, 폴더를 `/ (root)`로 고르고 저장해요.
4. 1~2분 뒤 `https://내아이디.github.io/quant-navigator/` 주소가 열려요.

## 친구 iPhone에 설치

1. **Safari**로 위 주소를 열어요 (카카오톡 안 브라우저 말고 Safari).
2. 아래 공유 버튼, **홈 화면에 추가**를 눌러요.
3. 홈 화면의 컴퍼스 아이콘(이름은 "츄테크")으로 열면 앱처럼 실행돼요.

> 홈 화면 아이콘 이름은 추가하는 순간에 정해져요. 이미 추가해 둔 상태라면 아이콘을 지우고 Safari에서 다시 홈 화면에 추가해야 새 이름이 보여요. 저장된 데이터는 지워지지 않아요.

## 처음 한 번 설정

- 보유 탭: 현재 TQQQ 수량, SGOV 수량, 예수금(달러)을 입력해요. 그 아래 칸에는 이번에 원화로 새로 넣을 돈(추가 투입금)을 적어요.
- 설정 탭: 목표 비중, 밴드, 수수료를 확인해요. 기본값은 50%, ±5%p, 0.1%예요.
- (선택) 설정 탭에 Twelve Data 무료 API 키를 넣으면 TQQQ와 SGOV 시세를 자동으로 불러와요(장중이면 현재가, 닫혀 있으면 마지막 종가). 키가 없으면 증권사 앱의 현재가를 직접 입력하면 돼요. 환율은 키 없이 자동으로 불러와요.

## 매일 쓰는 순서

1. 오늘 탭에서 **시세 불러오기** (또는 직접 입력).
2. **오늘 걸 주문**에 나온 수량과 지정가대로 증권사에서 LOC 주문을 걸어요.
3. **주문 걸었어요**를 눌러 등록해요.
4. 다음 날 시세를 새로 반영하면 **걸어둔 주문 확인**에 체결 여부 예상이 나와요. 증권사 체결 내역을 확인하고 **체결됐어요** 또는 **미체결, 삭제**를 눌러요.
5. 월급 등으로 돈을 더 넣을 때는 **보유 탭**의 **이번에 추가로 넣을 돈 (원)** 칸에 금액을 적어요. 오늘 탭의 **투입금 배치**에 TQQQ와 SGOV를 몇 주씩 살지 나와요. 증권사가 매수할 때 자동으로 환전해 주는 경우를 가정하고 환율로 달러를 계산해요. 매수를 반영하면 칸이 자동으로 비워져요.

## 밤 11시 30분 자동 점검과 알림

앱을 못 열어도 비율이 깨지면 폰으로 알림을 받을 수 있어요. 평일 밤 11시 30분(한국 시간, 미국 개장 시점)에 서버가 TQQQ와 SGOV의 현재가를 받아 앱과 같은 계산으로 점검하고, 알릴 게 있을 때만 알려요. 설정 방법은 **알림설정.md**를 보세요. 처음 한 번만 서버(Cloudflare Worker, 무료)와 알림 앱(ntfy)을 설정하면 돼요.
앱 설정 탭의 **🔔 자동 점검과 알림** 카드에서 연결 상태, 테스트 알림, 지금 점검하기, 알림 종류를 바꿀 수 있어요.

## 연습해 보기 (모의거래 모드)

화면 오른쪽 위의 **모의거래** 버튼을 누르면 연습 모드가 켜져요. 위쪽이 주황색으로 바뀌고, 지금 보유 수량을 복사해서 시작해요.
이 안에서는 시세를 바꾸고, 체결 반영을 눌러 보고, 설정을 바꿔 봐도 **실제 데이터에는 아무 영향이 없어요**.
**모의거래 끄기**를 누르거나 앱을 닫으면 연습 내용은 모두 사라지고 실제 모드로 돌아와요.

## 업데이트

저장소의 파일을 새 버전으로 바꿔 올리면 돼요. 앱은 인터넷이 연결돼 있으면 열 때마다 최신 파일을 받아요.

## 백업

기록 탭의 **백업 복사**를 눌러 메모 앱에 붙여 두세요. Safari의 사이트 데이터를 지우거나 앱을 삭제하면 저장된 데이터가 사라질 수 있어요. 백업에는 API 키와 알림 연결 코드가 들어가지 않아요. 복원한 뒤에는 연결 코드를 다시 넣어야 할 수 있어요(복원할 때 이 기기의 연결은 그대로 유지돼요).
