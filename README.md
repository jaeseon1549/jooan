# 퀀트 내비게이터

TQQQ와 SGOV를 섀넌의 도깨비 전략으로 굴릴 때, 오늘 걸 LOC 주문(수량, 지정가)을 계산해 주는 iPhone용 웹앱(PWA)이에요.
AppSheet, 구글 시트 없이 이 파일들만으로 동작하고, 데이터는 폰 안에만 저장돼요.

## 파일 구성 (저장소 맨 위 폴더에 그대로 올리기)

```
index.html
style.css
logic.js              ← 전략 계산 (비중, 지정가, 수량, 투입금 배치)
app.js                ← 화면과 동작
sw.js                 ← 오프라인 지원
manifest.webmanifest  ← 홈 화면 앱 정보
icons/
  icon-180.png
  icon-192.png
  icon-512.png
  icon-512-maskable.png
```

## 올리는 방법 (GitHub Pages)

1. GitHub에서 새 저장소를 만들어요 (예: `quant-navigator`, Public).
2. 위 파일과 `icons` 폴더를 저장소 맨 위에 올려요 (Add file, Upload files).
3. Settings, Pages에서 Branch를 `main`, 폴더를 `/ (root)`로 고르고 저장해요.
4. 1~2분 뒤 `https://내아이디.github.io/quant-navigator/` 주소가 열려요.

## 친구 iPhone에 설치

1. **Safari**로 위 주소를 열어요 (카카오톡 안 브라우저 말고 Safari).
2. 아래 공유 버튼, **홈 화면에 추가**를 눌러요.
3. 홈 화면의 컴퍼스 아이콘으로 열면 앱처럼 실행돼요.

## 처음 한 번 설정

- 보유 탭: 현재 TQQQ 수량, SGOV 수량, 예수금(달러)을 입력해요.
- 설정 탭: 목표 비중, 밴드, 수수료를 확인해요. 기본값은 50%, ±5%p, 0.1%예요.
- (선택) 설정 탭에 Twelve Data 무료 API 키를 넣으면 TQQQ와 SGOV 종가를 자동으로 불러와요. 키가 없으면 증권사 앱의 종가를 직접 입력하면 돼요. 환율은 키 없이 자동으로 불러와요.

## 매일 쓰는 순서

1. 오늘 탭에서 **시세 불러오기** (또는 직접 입력).
2. **오늘 걸 주문**에 나온 수량과 지정가대로 증권사에서 LOC 주문을 걸어요.
3. **주문 걸었어요**를 눌러 등록해요.
4. 다음 날 시세를 새로 반영하면 **걸어둔 주문 확인**에 체결 여부 예상이 나와요. 증권사 체결 내역을 확인하고 **체결됐어요** 또는 **미체결, 삭제**를 눌러요.
5. 월급 등으로 돈을 더 넣을 때는 **추가 투입금(원)** 칸에 금액을 넣으면 매수 수량을 계산해 줘요.

## 업데이트

저장소의 파일을 새 버전으로 바꿔 올리면 돼요. 앱은 인터넷이 연결돼 있으면 열 때마다 최신 파일을 받아요.

## 백업

기록 탭의 **백업 복사**를 눌러 메모 앱에 붙여 두세요. Safari의 사이트 데이터를 지우거나 앱을 삭제하면 저장된 데이터가 사라질 수 있어요.

## 참고

참고용 계산 도구예요. 실제 주문 전에 증권사 화면의 수량, 가격, 예수금을 꼭 확인하세요.
